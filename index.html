Ready to export

Importing into Outlook safely: Outlook contacts sync to every phone and computer. Never import the clean file over the live Contacts folder — that doubles every contact or misses the merges, everywhere. Instead: (1) back up the .pst; (2) create a new, empty contacts folder that is not synced; (3) File → Open & Export → Import/Export → Import from another program or file → Comma Separated Values → choose the clean .csv → import into that new folder; (4) check a few contacts with long notes; (5) only then swap it in for the synced folder. Don't open the .csv in Excel first — Excel changes dates, phone numbers, and accents. Synology / iPhone / Mac use the .vcf instead.
